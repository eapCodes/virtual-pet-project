# Virtual Pet Project

A virtual pet / tamagotchi-style companion with an optional procedural dungeon crawler layer. Built as a learning project — Python core, planned Arduino port, custom PCB and 3D-printed hardware down the line.

Status: WIP

## Phases
- Phase 1: Core pet loop (stats, decay, actions) — Python, CLI
- Phase 2: GUI
- Phase 3: Arduino/embedded port
- Phase 4: Custom PCB + enclosure

See `DESIGN.md` for the full design writeup.
